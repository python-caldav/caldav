===========
Sans-GitHub
===========

I'm not easy with being dependent on centralized components owned by third-parties, GitHub being one of them.  Alternatives exists, some people prefer Codeberg.  I've thought deeply through it, and my conclusion is that I'm not exchanging a centralized service with a good network effect with another centralized network service, even if I like "org" better than "com" - so GitHub will remain the primary project platform for the foreseable future (we need a federated platform for exchanging git commits, anyone up for the task?)

The most important for me is to avoid lock-in.  Migrating away from GitHub should be easy.
