Compatibility features `supported-components.honoured` (a calendar accepts exactly the component types its supported-calendar-component-set lists, and all of them where it lists none, as RFC 4791 section 5.2.3 requires) and `create-calendar.with-supported-component-types.multiple` (a MKCALENDAR naming several component types gives a calendar taking them all).  Bedework 3.10, DAViCal, Synology and Stalwart report a VTODO-only set yet take a VEVENT, so they are `broken` on the first; CCS refuses a two-type MKCALENDAR, so it is `unsupported` on the second.  Both are probed by caldav-server-tester.
