The test-server configuration is now the union of all its sources: `tests/caldav_test_servers.yaml`, `~/.config/caldav/test_servers.yaml` (and their `.json` variants) and the `test_allowed` sections of the caldav configuration file.  Before, the first source found was used alone, so a test-server yaml hid the `test_allowed` servers.  On a name clash the source listed first wins.  `tests/caldav_test_servers.yaml` is now looked up in the checkout instead of relative to the current directory, and `ExternalTestServer.is_accessible()` checks that the server's host accepts connections on its port instead of always returning `True`.
