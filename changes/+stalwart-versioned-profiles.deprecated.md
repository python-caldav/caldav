The `stalwart` compatibility profile is renamed `stalwart_0_16`, as it was measured against Stalwart v0.16, and `stalwart_1_1` is added: Stalwart v1.1 fixed several of the v0.16 issues, but no longer matches a comp-type-less prop-filter search, and treats `@` and `%40` in a path as the same resource.  The old name still works, as `stalwart_0_16`: `features: stalwart` or `base: stalwart` in a config gives a FutureWarning, and `compatibility_hints.stalwart` in code a DeprecationWarning.
