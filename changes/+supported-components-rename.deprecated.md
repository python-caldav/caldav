The compatibility feature `get-supported-components` is now `supported-components.property-exists`, under a new grouping node `supported-components` for the CALDAV:supported-calendar-component-set property.  A configuration setting the old name still works and gives a DeprecationWarning; `is_supported("get-supported-components")` raises, as for any unknown feature.  The Robur and Purelymail profiles use the new name.
