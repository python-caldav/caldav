The `zimbra` compatibility profile is renamed `zimbra_8_8`, as it was measured against a Zimbra 8.8 docker image, and `zimbra_10_1` is added: Zimbra 10.1 refuses a PUT of a UID the calendar already holds with 412 rather than 403 or 409.  The old name still works, as `zimbra_8_8`: `features: zimbra` or `base: zimbra` in a config gives a FutureWarning, and `compatibility_hints.zimbra` in code a DeprecationWarning.
