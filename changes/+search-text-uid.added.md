New feature `search.text.uid`: a calendar-query with a UID filter works.  iCloud answers it with 412 (https://github.com/python-caldav/caldav/issues/783), and its profile sets it to `ungraceful`.  Where it is not set, it is what `search.text` says: a feature list with `search.text` unsupported, broken or ungraceful therefore skips the search by UID, fetching `<uid>.ics` and, failing that, all objects instead, so set `search.text.uid: full` if a UID search works on that server.
