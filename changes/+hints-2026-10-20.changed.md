`compatibility_hints`: several server profiles are updated from a caldav-server-tester run, so with `features: <server>` configured, `is_supported()` may give a different answer for the features named here.

- `calendar-color`, `calendar-color.hex` and `calendar-order` are measured instead of left at the default `fragile`: all three are `full` for Xandikos, Nextcloud (and so ecloud, which inherits its profile), CCS, Stalwart, Cyrus, Posteo and Robur; Bedework 3 stores both colours but not `calendar-order`; SOGo takes a hex colour but not a colour name; OX App Suite takes a hex colour, returns a fixed colour whatever name is set, and does not store `calendar-order`.
- OX App Suite: `scheduling` is `full` (it was `unknown`), with `scheduling.schedule-tag` unsupported; inbox delivery and auto-scheduling stay `unknown`.
- Stalwart: `search.time-range.todo.no-dtstart.no-due` is `unsupported`.
- GMX: `search.recurrences.includes-implicit.infinite-scope` is `fragile` (it was `full`): it failed in one run and passed in the next.
- `well-known`: `unsupported` for Posteo, `full` for Robur.
