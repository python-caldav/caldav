An href is decoded once.  A UID holding a `/` is stored as `%252F` by `save()` and by iCloud, and a second decode turned that into a `/`: `search()`, `children()` and sync results for a UID that is a URL pointed at a URL that named nothing, `multiget()` returned any object with a `/` in its UID under a URL that does not exist, and a `search()` that loads its results with a multiget dropped such objects without a word.  `calendars()` did the same to a calendar whose name holds a `/`.
