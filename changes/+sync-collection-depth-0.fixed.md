The sync-collection REPORT (`Calendar.get_objects_by_sync_token()`, `AsyncDAVClient.sync_collection()`) is now sent with `Depth: 0`, as [RFC 6578 section 3.2](https://datatracker.ietf.org/doc/html/rfc6578#section-3.2) requires, instead of `Depth: 1`; the `depth` parameter of `AsyncDAVClient.sync_collection()` now defaults to 0.  None of the servers in the test suite behaves differently, but a strict server may reject the old request with a 400.
