`caldav.config.get_test_setting` and `caldav.config.get_all_test_servers` are test tooling, not configuration: they moved to `caldav.testing.selection`, with the rest of the code that picks a test server for `PYTHON_CALDAV_USE_TEST_SERVER`.  The old names still work, with a DeprecationWarning.  A section with `test_allowed: true` and `disable: true` is no longer offered as a test server.
