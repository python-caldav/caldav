`compatibility_hints`: several server profiles are updated from a caldav-server-tester run against all test servers, so with `features: <server>` configured, `is_supported()` may give a different answer for the features named here.

- Radicale 3.9.0 fixed the `i;octet` collation and `If-Match: *`, so `search.text.case-sensitive` and `save-load.mutable.if-match-wildcard` are back to the default `full`.  The `radicale` profile has no version: on an older Radicale, configure these two as `unsupported`.
- Xandikos 0.4.10 refuses a malformed sync token with 412 and valid-sync-token, like a well-formed one, instead of crashing with a 500: `sync-token.invalid-token` is a `quirk`, no longer `ungraceful`.
- `save-load.icalendar.tzid-link` is a `quirk` for OX App Suite and GMX, which store `Europe/Oslo` as `Europe/Berlin`.
- Bedework 5 drops X- parameters (`save-load.icalendar.x-parameter`), as Bedework 3.10 does.
