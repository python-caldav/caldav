The `supported-report-set` and `current-user-privilege-set` properties from `propfind()` were the raw lxml element.  They are now lists of the report and privilege names in Clark notation, e.g. `["{urn:ietf:params:xml:ns:caldav}calendar-query", "{DAV:}sync-collection"]`.  Code that walked the returned element has to read the list instead.
