Compatibility features `delete.if-match` (a DELETE with a stale If-Match is refused with 412; SOGo deletes the object anyway, while it refuses a stale If-Match on PUT), `save-load.event.floating` (an event with a floating DTSTART/DTEND is stored floating; SOGo pins it to TZID=Etc/UTC) and `save-load.icalendar.attendee-params` (ATTENDEE parameters are stored as sent; SOGo adds RSVP=TRUE, which changes the meaning, as the default is FALSE).  The SOGo profile has all three.
