Config file keys starting with `test_` are now reserved for test tooling, so other programs sharing the config file can drop them.  A section is marked for testing with `test_allowed: true` rather than `testing_allowed: true`, and the order test servers are tried in is set with `test_priority` rather than `priority`.  The old names still work, but emit a `DeprecationWarning`.  `test_priority` (or `priority`) in a section of the main config file was ignored before; it is now honoured.
