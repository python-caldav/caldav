New server hint `save-load.icalendar.tzid-link`: whether a server stores a TZID that is a link name of the tz database, such as Europe/Oslo (a link to Europe/Berlin).  Bedework 5 refuses every such object with 403, VTIMEZONE or not, so on a server where it is `ungraceful`, `save()` sends the zone the link points to instead; a link and its zone agree on every time since 1970, so the times stay where they were.  `save(raw_data=...)` still sends its bytes unchanged.
